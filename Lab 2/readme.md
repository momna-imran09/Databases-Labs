## 📌 Introduction
Welcome to **Lab 02**. This project implements a relational database schema for a **Point of Sale (POS)** system. It demonstrates how to create relational tables, enforce foreign key constraints, manage inventory, and track customer transactions using MySQL.

---

## 🛠️ Step-by-Step Instructions: How to Run on XAMPP & phpMyAdmin

Follow these exact steps to set up and run the POS database locally on your machine:

### Step 1: Start XAMPP Services
1. Open the **XAMPP Control Panel** on your computer.
2. Click the **Start** button next to **Apache**.
3. Click the **Start** button next to **MySQL**. Ensure both modules turn green.

### Step 2: Open phpMyAdmin
1. Open your web browser (Chrome, Edge, Firefox, etc.).
2. Type the following URL in the address bar and press **Enter**:
   ```text
   http://localhost/phpmyadmin/
