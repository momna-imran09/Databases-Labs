## 📌 Introduction
Welcome to **Lab 06**. In database querying, filtering allows us to extract specific subsets of data from tables based on given criteria. This lab focuses on mastering **Comparison Operators** (`=`, `!=` or `<>`, `>`, `<`, `>=`, `<=`) and **Logical Operators** (`AND`, `OR`, `NOT`) using **MySQL** via **phpMyAdmin**.

---

## ⚙️ Operators Covered in this Lab

### 1. Comparison Operators
* **`=`** (Equal to)
* **`<>` or `!=`** (Not equal to)
* **`>`** (Greater than)
* **`<`** (Less than)
* **`>=`** (Greater than or equal to)
* **`<=`** (Less than or equal to)

### 2. Logical Operators
* **`AND`:** Returns records only if **all** conditions separated by `AND` are true.
* **`OR`:** Returns records if **any** of the conditions separated by `OR` is true.
* **`NOT`:** Negates or reverses the result of a condition.
