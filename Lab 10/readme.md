## 📌 Introduction
Welcome to **Lab 10**. Scalar functions operate on a single value and return a single value. This lab focuses on built-in **String Functions** in MySQL, which are used to manipulate text data, format strings, extract substrings, convert casing, and perform text sanitization.

---

## ⚙️ String Functions Covered in this Lab

### 1. `UPPER()` & `LOWER()`
* Converts a text string to all uppercase or all lowercase letters.

### 2. `CONCAT()`
* Joins two or more string values together into a single string.

### 3. `LENGTH()` & `CHAR_LENGTH()`
* Returns the length of a string in bytes or characters respectively.

### 4. `SUBSTRING()`
* Extracts a substring from a string starting at a specified position for a given length.

### 5. `REPLACE()`
* Replaces all occurrences of a specified substring within a string with a new substring.

### 6. `TRIM()`
* Removes leading and trailing spaces from a string.
